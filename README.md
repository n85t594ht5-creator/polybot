# PolyBot — установка на ПК (Windows)

## 1. Python
Скачай https://www.python.org/downloads/ → при установке поставь галочку **Add Python to PATH**.

## 2. Проект
Распакуй папку `polybot`, открой в ней терминал (ПКМ → «Открыть в терминале») и выполни:

```
pip install -r requirements.txt
copy .env.example .env
```

## 3. Paper-режим (без ключей, реальные котировки)
```
python bot.py
```
Бот сканирует рынки Polymarket «Up or Down» по BTC/ETH/SOL, берёт цены с Binance
и записывает виртуальные сделки. Смотри `bot.log` и `trades.csv`.
Остановить — Ctrl+C. Состояние сохраняется в `state.json` и подхватывается при рестарте.

**Гоняй минимум 1–2 недели.** Строка `STATS ...` в логе покажет winrate и Profit Factor.
Если PF < 1.3 — на живые деньги переходить бессмысленно.

## 4. Live-режим — куда вставлять ключ
Открой файл `.env` в Блокноте и заполни:

```
MODE=live
POLY_PRIVATE_KEY=0xабв...      ← приватный ключ Polygon-кошелька с USDC
POLY_FUNDER=0x...              ← адрес из Polymarket (Profile → Settings), если логинился через email
POLY_SIGNATURE_TYPE=0          ← 0 для MetaMask, 1 для email-логина
```

Правила:
- Файл `.env` никому не показывать, никуда не загружать, не пересылать.
- Заведи **отдельный** кошелёк только под бота, положи на него $50–100. Не основной.
- Перед первым live-запуском в Polymarket сделай хотя бы одну ручную сделку —
  это включает разрешения (allowance) на USDC.
- Первый live-запуск: `BANKROLL=50`, `MAX_POSITIONS=3`.

## 5. Telegram-уведомления (по желанию)
`TELEGRAM_BOT_TOKEN` — от @BotFather, `TELEGRAM_CHAT_ID` — твой ID (узнать через @userinfobot).

## Настройки
Все параметры стратегии — в `.env` с комментариями. Ключевые: `MAX_ENTRY`, `MIN_ELAPSED`, `MIN_MOVE`.

## Ограничения этой версии
- Резолв paper-сделок считается по цене Binance на конец окна; Polymarket использует Chainlink —
  в редких пограничных случаях результат может отличаться.
- Live-ордер ставится лимиткой по текущему ask; если не исполнился — висит в стакане.
  Проверяй открытые ордера на сайте в первые дни.
